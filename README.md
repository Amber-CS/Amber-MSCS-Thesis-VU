# Amber-MSCS-Thesis-VU
AMBER — Deep Learning Approach for Plant Leaf Disease Detection Using MobileNetV2 and Explainable AI (XAI) | MS Computer Science Thesis, Virtual University of Pakistan (VU).


This project is developed using **Python and TensorFlow** for plant leaf disease detection and classification with MobileNetV2. It also uses **Grad-CAM (Explainable AI)** to visualize the regions of leaf images that influence the model's predictions.

**Technologies:** Python, TensorFlow, MobileNetV2, Grad-CAM (XAI).
